# Exam HQ 2027 Roadmap APK

This Android app displays the standalone CBSE Class XII / JEE Main / BITSAT roadmap offline. It contains only the major phases and exam countdowns.

## Download the APK

Open the repository's Actions tab, choose **Build Exam HQ 2027 Roadmap APK**, open the latest successful run, and download the **Exam-HQ-2027-Roadmap** artifact. Extract the ZIP and install the APK on your Android device.

The APK is a debug build intended for personal use. The HTML page and JavaScript are bundled in the app, so the roadmap and countdowns work offline.
